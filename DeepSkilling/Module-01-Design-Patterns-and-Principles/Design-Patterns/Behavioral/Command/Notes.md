# Command Pattern

## Definition

Command is a Behavioral Design Pattern that encapsulates a request as an object, allowing requests to be parameterized, queued, logged, or undone.

---

## Components

- Command Interface
- Concrete Command
- Receiver
- Invoker
- Client

---

## Advantages

- Loose coupling
- Easy to extend
- Supports undo/redo
- Enables command queues

---

## Disadvantages

- Increases the number of classes
- Slightly more complex

---

## Real-World Example

TV Remote

Restaurant Order System

---

## Industry Usage

- GUI Buttons
- Task Scheduling
- Job Queues
- Undo/Redo Operations
