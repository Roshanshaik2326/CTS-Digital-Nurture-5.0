# Strategy Pattern

## Definition

Strategy is a Behavioral Design Pattern that allows selecting an algorithm or behavior at runtime.

---

## Purpose

Encapsulate interchangeable algorithms and switch between them without modifying the client code.

---

## Components

- Strategy Interface
- Concrete Strategies
- Context
- Client

---

## Advantages

- Easy to switch algorithms
- Follows Open/Closed Principle
- Reduces conditional statements
- Promotes code reuse

---

## Disadvantages

- Increases the number of classes
- Clients must know the available strategies

---

## Real-World Example

Navigation apps allowing users to choose Car, Walking, or Bicycle routes.

---

## Industry Usage

- Payment Processing
- Discount Calculation
- Authentication Methods
- Sorting Algorithms
- Shipping Cost Calculation
