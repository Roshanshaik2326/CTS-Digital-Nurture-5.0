# Adapter Pattern

## Definition

Adapter is a Structural Design Pattern that allows incompatible interfaces to work together.

---

## Purpose

Acts as a bridge between two incompatible classes.

---

## Components

- Target Interface
- Adapter
- Adaptee
- Client

---

## Advantages

- Reuse existing classes
- Loose coupling
- Easy integration

---

## Disadvantages

- Additional layer
- Slight increase in complexity

---

## Real World Example

Type-C to HDMI Adapter.

---

## Industry Usage

- Payment Gateway Integration
- Legacy System Integration
- Third-party APIs
- Cloud Services
