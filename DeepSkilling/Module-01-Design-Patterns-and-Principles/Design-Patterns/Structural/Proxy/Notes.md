# Proxy Pattern

## Definition

Proxy is a Structural Design Pattern that provides a placeholder or representative object to control access to another object.

---

## Purpose

Control access to an object by performing checks before forwarding requests.

---

## Components

- Subject Interface
- Real Subject
- Proxy
- Client

---

## Advantages

- Access control
- Lazy initialization
- Improved security
- Better performance

---

## Disadvantages

- Adds an extra layer
- Slight increase in complexity

---

## Real-World Example

A security guard checks whether a visitor has permission before allowing entry into a restricted area.

---

## Industry Usage

- Authentication
- Authorization
- Lazy Loading
- Remote Services
- API Gateways
