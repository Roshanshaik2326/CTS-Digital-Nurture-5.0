# Decorator Pattern

## Definition

Decorator is a Structural Design Pattern that adds new functionality to an object dynamically without changing its existing code.

---

## Purpose

Extend an object's behavior without modifying the original class.

---

## Components

- Component
- Concrete Component
- Decorator
- Concrete Decorator

---

## Advantages

- Follows Open/Closed Principle
- Flexible
- Reusable
- Easy to extend

---

## Disadvantages

- Multiple small classes
- Slight increase in complexity

---

## Real World Example

Pizza with Extra Cheese, Olives, and Toppings.

---

## Industry Usage

- Order Customization
- Logging
- Compression
- Encryption
- Stream APIs
