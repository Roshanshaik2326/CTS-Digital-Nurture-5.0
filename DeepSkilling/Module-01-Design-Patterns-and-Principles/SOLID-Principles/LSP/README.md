# Liskov Substitution Principle (LSP)

## Objective

Learn how inheritance should preserve the expected behavior of the base class.

## Problem

A child class should never break the functionality promised by its parent.

## Solution

Use inheritance correctly and separate optional behaviors using interfaces.
