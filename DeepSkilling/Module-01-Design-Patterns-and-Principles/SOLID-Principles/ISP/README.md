# Interface Segregation Principle (ISP)

## Objective

Learn how to design small and focused interfaces.

## Problem

Large interfaces force classes to implement methods they don't need.

## Solution

Split large interfaces into multiple smaller interfaces.

## Project Structure

- IWorkable
- IEatable
- Human
- Robot

## Technologies Used

- C#
- .NET Console Application
- Object-Oriented Programming

## How to Run

```bash
dotnet restore
dotnet run
```
