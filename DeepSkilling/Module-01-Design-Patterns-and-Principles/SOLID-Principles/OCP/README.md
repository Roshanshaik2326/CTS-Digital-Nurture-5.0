# Open/Closed Principle (OCP)

## Objective

Understand how to extend software behavior without modifying existing code.

## Problem

Changing existing code every time a new requirement arrives increases the chance of introducing bugs.

## Solution

Use abstraction and inheritance so new behavior can be added by creating new classes.

## Project Structure

- Customer (Abstract Class)
- RegularCustomer
- PremiumCustomer

## Technologies Used

- C#
- .NET Console Application
- Object-Oriented Programming

## How to Run

```bash
dotnet restore
dotnet run
```
