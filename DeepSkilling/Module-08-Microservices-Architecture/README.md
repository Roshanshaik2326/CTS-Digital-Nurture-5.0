# Module 08 – Microservices Architecture using ASP.NET Core Web

## Overview

This module introduces Microservices Architecture and demonstrates how to secure REST APIs using JWT (JSON Web Token) Authentication in ASP.NET Core Web API.

## Exercise

### Exercise 1 – JWT Authentication in ASP.NET Core Web API

## Objectives

- Understand Microservices Architecture
- Learn Authentication and Authorization
- Configure JWT Authentication
- Generate JWT Tokens
- Secure API Endpoints
- Test APIs using Swagger

## Technologies Used

- ASP.NET Core Web API
- .NET 10
- JWT Bearer Authentication
- Swagger (Swashbuckle)
- C#
