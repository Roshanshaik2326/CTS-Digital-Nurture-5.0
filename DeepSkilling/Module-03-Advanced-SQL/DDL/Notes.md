# Data Definition Language (DDL)

DDL (Data Definition Language) is used to define and modify the structure of database objects.

## Commands

- CREATE → Creates database objects.
- ALTER → Modifies existing tables.
- DROP → Deletes tables permanently.
- TRUNCATE → Removes all rows while keeping the table.
- RENAME → Renames database objects.

## Advantages

- Organizes database structure.
- Maintains relationships using constraints.
- Supports schema evolution.

## Constraints Used

- PRIMARY KEY
- FOREIGN KEY
- NOT NULL
