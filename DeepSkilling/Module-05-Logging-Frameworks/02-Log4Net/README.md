# Log4Net

## Objective

To learn how to use the Log4Net framework for logging in .NET applications.

## Description

Log4Net is an open-source logging framework developed by the Apache Software Foundation. It provides flexible logging capabilities and supports multiple output destinations such as the console, files, databases, and email.

## Topics Covered

- Introduction to Log4Net
- Installing Log4Net using NuGet
- Configuring log4net.config
- Console Appender
- Logging Levels
- Generating Log Messages

## Output

A C# console application that demonstrates logging using the Log4Net framework.

## Learning Outcome

After completing this exercise, you will be able to:

- Install Log4Net in a .NET project
- Configure Log4Net using an XML configuration file
- Generate log messages of different severity levels
- Understand how logging frameworks simplify application monitoring
