# Serilog

## What is Serilog?

Serilog is an open-source structured logging framework for .NET applications. It helps developers capture meaningful log data that can be easily searched and analyzed.

---

## Features

- Structured logging
- Easy configuration
- Multiple sinks (Console, File, Database, Cloud)
- High performance
- Rich log formatting

---

## Common Logging Levels

- Verbose
- Debug
- Information
- Warning
- Error
- Fatal

---

## Advantages

- Easy integration with .NET
- Supports structured data
- Multiple output destinations
- Improves debugging and monitoring

---

## Interview Questions

### 1. What is Serilog?

Serilog is a structured logging framework for .NET applications.

### 2. What is a Sink in Serilog?

A sink is the destination where log messages are written, such as the console or a file.

### 3. Name some common Serilog sinks.

Console, File, SQL Server, Elasticsearch, Seq, Azure.

### 4. Why is structured logging useful?

It stores logs in a structured format, making them easier to search, filter, and analyze.

### 5. What are the common logging levels in Serilog?

Verbose, Debug, Information, Warning, Error, and Fatal.
