# Big O Analysis

## Definition

Big O notation is used to measure the efficiency of an algorithm.

It tells us how execution time grows as the input size increases.

---

## Types

### O(1)

Constant Time

Example:

Accessing an array element.

---

### O(log n)

Logarithmic Time

Example:

Binary Search

---

### O(n)

Linear Time

Example:

Linear Search

---

### O(n log n)

Efficient Sorting

Example:

Merge Sort

Quick Sort (Average)

---

### O(n²)

Quadratic Time

Example:

Bubble Sort

Selection Sort

---

## Why Big O?

- Compare algorithms
- Improve application performance
- Reduce execution time
- Improve scalability

---

## Real World Example

Searching contacts

Linear Search → O(n)

Binary Search → O(log n)
