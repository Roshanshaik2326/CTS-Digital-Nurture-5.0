# Arrays

## Definition

An Array is a collection of elements of the same data type stored in contiguous memory locations.

---

## Features

- Fixed Size
- Indexed
- Fast Access
- Same Data Type

---

## Advantages

- O(1) Random Access
- Easy Traversal
- Memory Efficient

---

## Disadvantages

- Fixed Size
- Insertion/Deletion is costly
- Stores only one data type

---

## Operations

- Traversal
- Searching
- Updating
- Finding Maximum
- Finding Minimum

---

## Time Complexity

Access : O(1)

Traversal : O(n)

Search : O(n)

Update : O(1)

---
