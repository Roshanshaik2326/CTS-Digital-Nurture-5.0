# Insertion Sort

## Definition

Insertion Sort builds a sorted array one element at a time by inserting each new element into its correct position.

---

## Steps

1. Assume the first element is sorted.
2. Pick the next element.
3. Compare it with previous elements.
4. Shift larger elements one position to the right.
5. Insert the current element into the correct position.

---

## Advantages

- Easy to implement
- Efficient for small datasets
- Stable sorting algorithm
- Adaptive (fast on nearly sorted arrays)

---

## Disadvantages

- Slow for large datasets
- O(n²) in average and worst cases

---

## Time Complexity

Best Case : O(n)

Average Case : O(n²)

Worst Case : O(n²)

---

## Space Complexity

O(1)

---

## Real World Example

Employee Salary Sorting

Student Marks Ranking

Library Book Arrangement

---

## Industry Usage

Useful for small datasets and nearly sorted collections.
