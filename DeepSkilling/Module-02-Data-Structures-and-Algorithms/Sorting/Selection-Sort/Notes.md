# Selection Sort

## Definition

Selection Sort repeatedly selects the smallest element from the unsorted portion and places it at the correct position.

---

## Steps

1. Find the minimum element.
2. Swap it with the first unsorted element.
3. Move the boundary of the sorted section.
4. Repeat until the array is sorted.

---

## Advantages

- Simple implementation
- Fewer swaps than Bubble Sort
- Performs well for very small datasets

---

## Disadvantages

- O(n²) time complexity
- Inefficient for large datasets

---

## Time Complexity

Best Case : O(n²)

Average Case : O(n²)

Worst Case : O(n²)

---

## Space Complexity

O(1)

---

## Real World Example

Sorting Product Prices

Sorting Student Marks

Sorting Employee IDs

---

## Industry Usage

Suitable for learning and very small collections.
