# Bubble Sort

## Definition

Bubble Sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

---

## Steps

1. Compare adjacent elements.
2. Swap if left element is greater.
3. Repeat until no swaps are needed.

---

## Advantages

- Easy to understand
- Easy to implement
- Good for small datasets

---

## Disadvantages

- Slow for large datasets
- High time complexity

---

## Time Complexity

Best Case : O(n)

Average Case : O(n²)

Worst Case : O(n²)

---

## Space Complexity

O(1)

---

## Real World Example

Sorting Student Marks

Sorting Employee IDs

Sorting Product Prices

---

## Industry Usage

Suitable only for educational purposes or very small datasets.
