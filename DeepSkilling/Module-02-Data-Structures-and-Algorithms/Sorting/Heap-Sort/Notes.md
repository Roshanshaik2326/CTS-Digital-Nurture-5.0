# Heap Sort

## Definition

Heap Sort is a comparison-based sorting algorithm that uses a Binary Heap data structure to sort elements efficiently.

---

## Steps

1. Build a Max Heap.
2. Swap the root with the last element.
3. Reduce the heap size.
4. Heapify the root.
5. Repeat until the array is sorted.

---

## Advantages

- Guaranteed O(n log n)
- In-place sorting
- No worst-case degradation like Quick Sort

---

## Disadvantages

- Not stable
- More complex than Bubble or Insertion Sort

---

## Time Complexity

Best Case : O(n log n)

Average Case : O(n log n)

Worst Case : O(n log n)

---

## Space Complexity

O(1)
