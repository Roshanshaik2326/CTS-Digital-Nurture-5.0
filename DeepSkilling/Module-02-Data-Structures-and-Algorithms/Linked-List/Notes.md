# Linked List

## Definition

A Linked List is a linear data structure consisting of nodes, where each node contains data and a reference to the next node.

---

## Components

- Node
- Head
- Next Pointer

---

## Advantages

- Dynamic size
- Efficient insertion
- Efficient deletion
- No contiguous memory required

---

## Disadvantages

- Sequential access
- Extra memory for pointers
- Slower searching than arrays

---

## Time Complexity

Insertion at End : O(n)

Insertion at Beginning : O(1)

Deletion : O(n)

Search : O(n)

Traversal : O(n)
