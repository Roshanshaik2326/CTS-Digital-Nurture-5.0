# Retail Inventory Mini Project Notes

## Overview

This project demonstrates how Entity Framework Core can be used to build a simple inventory management system.

## Entity

Product

- ProductId
- ProductName
- Category
- Price
- Quantity

## Operations Performed

### Create

Insert sample products into the database.

### Read

Retrieve and display all products.

### Update

Modify the price of an existing product.

### Delete

Remove a product from inventory.

### Search

Retrieve products belonging to a specific category using LINQ.

## Key EF Core Concepts Used

- DbContext
- DbSet
- EnsureCreated()
- SaveChanges()
- Where()
- FirstOrDefault()
- Any()

## Summary

This project combines the core concepts of Entity Framework Core into a practical inventory management application.
