# Retail Inventory Management System using Entity Framework Core

## Objective

Build a simple inventory management application that demonstrates Entity Framework Core concepts in a real-world scenario.

## Features

- Add Products
- Display Products
- Update Product Price
- Search Products by Category
- Delete Products

## Technologies Used

- C#
- .NET
- Entity Framework Core
- SQL Server
- LINQ

## Concepts Applied

- DbContext
- DbSet
- CRUD Operations
- LINQ Queries
- Code-First Database Creation

## Project

RetailInventorySystem
