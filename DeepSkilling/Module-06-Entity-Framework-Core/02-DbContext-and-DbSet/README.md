# DbContext and DbSet

## Objective

Learn how to configure Entity Framework Core using `DbContext` and `DbSet` to connect a .NET application with SQL Server.

## Concepts Covered

- Entity Class
- DbContext
- DbSet
- SQL Server Connection
- EF Core Configuration
- Database Creation
- Code First Approach

## Project

**StudentManagementDemo**

This project demonstrates:

- Creating an Entity class
- Creating a DbContext class
- Connecting SQL Server
- Creating a database using EF Core

## Files

- Student.cs
- AppDbContext.cs
- Program.cs

## Output

- SQL Server connection established successfully
- StudentDB database created
- Students table generated
