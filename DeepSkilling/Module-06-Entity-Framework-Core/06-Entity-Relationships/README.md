# Entity Relationships in Entity Framework Core

## Objective

Learn how to establish relationships between entities using Entity Framework Core.

## Concepts Covered

- One-to-Many Relationship
- Navigation Properties
- Foreign Keys
- Include()
- Related Data Retrieval

## Project

RelationshipDemo

The project demonstrates a Department–Employee relationship where one department contains multiple employees.

## Output

Displays departments and their associated employees using Entity Framework Core relationships.
