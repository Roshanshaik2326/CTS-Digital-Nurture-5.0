# LINQ Queries in Entity Framework Core

## Objective

Learn how to retrieve and filter data from a SQL Server database using LINQ with Entity Framework Core.

## Concepts Covered

- Where()
- FirstOrDefault()
- OrderBy()
- Select()
- Count()
- Any()

## Project

LINQDemo

The project demonstrates common LINQ queries using Entity Framework Core.

## Output

- Filtered records
- Sorted records
- First record
- Record count
- Selected columns
