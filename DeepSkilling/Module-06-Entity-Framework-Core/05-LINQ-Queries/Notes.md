# LINQ Queries Notes

## What is LINQ?

LINQ (Language Integrated Query) allows developers to query collections and databases using C# syntax instead of writing SQL.

## Common LINQ Methods

### Where()

Filters records based on a condition.

### FirstOrDefault()

Returns the first matching record or null if none exist.

### OrderBy()

Sorts data in ascending order.

### OrderByDescending()

Sorts data in descending order.

### Select()

Projects only the required columns.

### Count()

Returns the number of records.

### Any()

Checks whether any records exist.

## Advantages

- Strongly typed
- Easy to read
- IntelliSense support
- Reduces SQL code
- Integrates directly with C#

## Summary

LINQ provides a powerful and readable way to query data in Entity Framework Core applications.
