 # Module 06 – Entity Framework Core

## Overview

This module introduces Entity Framework Core (EF Core), Microsoft's modern Object-Relational Mapper (ORM) for .NET applications. EF Core enables developers to work with databases using C# objects instead of writing raw SQL queries, simplifying data access and improving productivity.

Throughout this module, various projects demonstrate how to configure EF Core, create databases using the Code-First approach, perform CRUD operations, execute LINQ queries, model relationships, implement the Repository Pattern, and build a practical inventory management application.

---

## Learning Objectives

- Understand Entity Framework Core architecture
- Configure DbContext and DbSet
- Create databases using Code-First Migrations
- Perform CRUD operations
- Query data using LINQ
- Build relationships between entities
- Implement the Repository Pattern
- Develop a mini project using EF Core
