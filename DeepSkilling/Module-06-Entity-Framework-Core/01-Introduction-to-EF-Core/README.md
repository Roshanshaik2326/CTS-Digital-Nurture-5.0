# Introduction to Entity Framework Core

## Objective
Understand the basics of Entity Framework Core (EF Core), its architecture, advantages, and how it simplifies database operations in .NET applications.

## What is Entity Framework Core?

Entity Framework Core (EF Core) is an open-source, lightweight, cross-platform Object Relational Mapper (ORM) developed by Microsoft. It enables developers to work with databases using .NET objects instead of writing raw SQL queries.

## Key Features

- Open Source
- Cross Platform
- ORM (Object Relational Mapper)
- Supports Code First, Database First, and Model First approaches
- LINQ Query Support
- Automatic CRUD Operations
- Migration Support

## Advantages

- Reduces boilerplate code
- Faster application development
- Strong integration with .NET
- Easy database management using migrations
- Simplifies data access using LINQ
