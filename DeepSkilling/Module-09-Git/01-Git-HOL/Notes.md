# Git HOL 1 Notes

## Commands

- git init - Initializes a Git repository.
- git status - Displays the current repository status.
- git add - Adds files to the staging area.
- git commit - Saves staged changes in the repository.

## Key Learning

- A Git repository is created using `git init`.
- Files must be staged before committing.
- Every commit creates a snapshot of the project.
