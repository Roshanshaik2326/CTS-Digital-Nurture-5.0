# HTTP Methods in ASP.NET Core Web API

## Objective

Learn how to implement RESTful CRUD operations using standard HTTP methods.

## Topics Covered

- GET
- POST
- PUT
- PATCH
- DELETE
- HTTP Status Codes
- IActionResult

## Project

ProductCRUDAPI

## Endpoints

- GET /api/product
- GET /api/product/{id}
- POST /api/product
- PUT /api/product/{id}
- PATCH /api/product/{id}/price
- DELETE /api/product/{id}

## Technologies

- ASP.NET Core Web API
- C#
- Swagger

## Learning Outcome

Understand how each HTTP method is used in RESTful API development and how to return appropriate HTTP responses.
