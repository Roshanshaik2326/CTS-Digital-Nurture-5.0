# Dependency Injection

## Objective

Learn how to implement Dependency Injection in ASP.NET Core Web API using interfaces and services.

## Topics Covered

- Dependency Injection
- Interfaces
- Services
- Constructor Injection
- Service Registration
- Scoped Lifetime

## Project

EmployeeServiceAPI

## Endpoints

GET /api/employee

GET /api/employee/{id}

## Technologies

- ASP.NET Core Web API
- C#
- Swagger

## Learning Outcome

Understand how ASP.NET Core injects dependencies using the built-in IoC container, making applications modular, testable, and maintainable.
