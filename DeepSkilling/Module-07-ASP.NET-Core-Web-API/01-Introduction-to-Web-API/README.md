# Introduction to ASP.NET Core Web API

## Objective

Learn the fundamentals of ASP.NET Core Web API and build your first REST API application.

## Topics Covered

- Introduction to Web API
- Client-Server Architecture
- REST Architecture
- HTTP Protocol
- JSON
- Controllers
- Routing
- Swagger UI
- API Testing

## Project

HelloAPI

The project demonstrates a simple ASP.NET Core Web API with a GET endpoint that returns a welcome message.

## Technologies Used

- ASP.NET Core Web API
- C#
- .NET
- Swagger (OpenAPI)

## API Endpoint

### GET

```
/api/hello
```

### Response

```
Welcome to ASP.NET Core Web API!
```

## Learning Outcome

After completing this topic, you will be able to:

- Understand RESTful APIs
- Create a Web API project
- Build a controller
- Configure routing
- Test APIs using Swagger
- Return HTTP responses

## Conclusion

This topic provides the foundation required to build enterprise-level REST APIs using ASP.NET Core.
