# Model Validation

## Objective

Learn how to validate incoming request data in ASP.NET Core Web API using Data Annotations.

## Topics Covered

- Required
- Range
- StringLength
- EmailAddress
- ModelState Validation
- BadRequest Response

## Project

StudentValidationAPI

## Endpoints

GET /api/student

POST /api/student

## Technologies

- ASP.NET Core Web API
- C#
- Swagger
- Data Annotations

## Learning Outcome

After completing this topic, you will be able to validate API request models, reject invalid requests, and return meaningful validation errors using ModelState.
