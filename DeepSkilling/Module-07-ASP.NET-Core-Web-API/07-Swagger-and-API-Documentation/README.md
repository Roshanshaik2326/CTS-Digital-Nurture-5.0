# Swagger and API Documentation

## Objective

Learn how to integrate Swagger (OpenAPI) into an ASP.NET Core Web API for interactive documentation and testing.

## Topics Covered

- Swagger
- OpenAPI
- Swagger UI
- API Metadata
- Interactive Testing

## Project

SwaggerDemoAPI

## Endpoints

- GET /api/Product
- GET /api/Product/{id}

## Technologies

- ASP.NET Core Web API
- Swagger (Swashbuckle)
- C#

## Learning Outcome

Understand how to document and test Web APIs using Swagger, making APIs easier to consume and maintain.
