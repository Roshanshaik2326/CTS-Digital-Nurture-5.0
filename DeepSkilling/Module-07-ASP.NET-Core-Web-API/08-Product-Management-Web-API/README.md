# Product Management Web API

## Objective

Develop a Product Management REST API using ASP.NET Core Web API.

## Topics Covered

- Controllers
- Routing
- CRUD Operations
- HTTP Methods
- Model Validation
- Dependency Injection
- Swagger

## Project

ProductManagementAPI

## Endpoints

- GET /api/Product
- GET /api/Product/{id}
- POST /api/Product
- PUT /api/Product/{id}
- DELETE /api/Product/{id}

## Technologies

- ASP.NET Core Web API
- C#
- Swagger
- Dependency Injection

## Learning Outcome

Build a complete RESTful API following clean architecture principles using services, validation, and dependency injection.
