# Angular Hands-On 4

## Objective

Implement a Template-Driven Form in Angular using ngModel and NgForm with built-in form validation.

---

## Topics Covered

- Template-Driven Forms
- FormsModule
- NgForm
- ngModel
- Form Submission
- Built-in Validators
- Validation Messages
- Reset Form
- Form State Classes

---

## Features Implemented

- Student Name input
- Student Email input
- Course Selection
- Terms and Conditions checkbox
- Submit Button
- Reset Button

---

## Validation

### Student Name

- Required
- Minimum 3 Characters

### Student Email

- Required
- Email Validation

### Course

- Required

### Terms

- Required

---

## User Interface

- Red border for invalid controls
- Green border for valid controls
- Validation messages
- Submit button disabled until the form becomes valid
- Success message after successful submission

---

## Technologies Used

- Angular 20
- TypeScript
- HTML
- CSS

---

## Learning Outcome

Successfully implemented a complete Template-Driven Form with Angular validation and form handling.
