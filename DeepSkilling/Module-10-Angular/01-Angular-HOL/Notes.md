# Angular Hands-On 1 - Notes

## Angular CLI

Angular CLI is the official command-line tool used to create, build, test and run Angular applications.

Useful Commands

ng new <project-name>

Creates a new Angular project.

ng serve

Runs the application locally.

ng generate component <component-name>

Generates a standalone Angular component.

## Standalone Components

Angular 22 creates standalone components by default.

Standalone components are imported directly into other components instead of being declared inside an NgModule.

## Routing

Angular Router enables navigation between different components without reloading the page.

The RouterOutlet directive displays the currently active routed component.
