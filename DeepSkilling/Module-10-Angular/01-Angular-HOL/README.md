# Angular Hands-On 1

## Objective

Set up the Angular development environment and create the initial Student Course Portal application.

## Tasks Performed

- Installed Angular CLI
- Created a new Angular project
- Configured CSS styling
- Enabled Angular Routing
- Generated standalone components
  - Header
  - Home
  - Course List
  - Student Profile
- Configured routing
- Created the basic Student Course Portal UI
- Successfully ran the application on localhost:4200

## Technologies Used

- Angular 22
- TypeScript
- HTML
- CSS
- Node.js
- npm

## Outcome

Successfully created and executed the Student Course Portal Angular application with routing and reusable standalone components.
