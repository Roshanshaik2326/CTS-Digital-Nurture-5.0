# Angular Hands-On 2

## Objective

Implement Angular data binding, lifecycle hooks, and component communication using the Student Course Portal application.

---

## Topics Covered

- Interpolation
- Property Binding
- Event Binding
- Two-Way Binding
- FormsModule
- Lifecycle Hooks
- ngOnInit
- ngOnChanges
- ngOnDestroy
- @Input
- @Output
- EventEmitter
- Parent-Child Communication

---

## Tasks Performed

### Task 1

- Implemented interpolation.
- Added property binding.
- Added event binding.
- Implemented two-way data binding using ngModel.

### Task 2

- Implemented Angular lifecycle hooks.
- Used ngOnInit().
- Used ngOnChanges().
- Used ngOnDestroy().

### Task 3

- Created CourseCardComponent.
- Passed data from parent to child using @Input.
- Sent events from child to parent using @Output and EventEmitter.

---

## Expected Outcome

- Dynamic UI updates using Angular bindings.
- Lifecycle hooks executed successfully.
- Parent and child components communicated successfully.
- Student Course Portal became more interactive.
